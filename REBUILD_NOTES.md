# Island Sunnyside Rebuild Notes

## Removed

- Old automation/task system.
- Previous cage/totem/vault/galleon progression.
- Non-Sunnyside runtime asset dependencies.
- Broken transparent terrain tile crops that created black voids.

## Added

- Clean island-life gameplay loop: build, farm, fish, explore.
- Village starter layout with Sunnyside homes/workshop/well/docks.
- Farm plots with seed planting and crop harvesting.
- Ambient wildlife using Sunnyside animals.
- A* right-click pathfinding preserved and simplified for the new world.
- New Sunnyside-only asset manifest and renderer.

## Known production next steps

- Add authored quests around home upgrades, farming and sailing.
- Add true multi-direction character sprites if a matching pack is selected later.
- Add interior scenes for homes/workshops.
- Replace placeholder combat enemies with Island-specific wildlife/spirits or remove combat entirely depending on final design.
